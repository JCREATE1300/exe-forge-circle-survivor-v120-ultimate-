# circle-survivor-v120-ultimate- - Windows Installer

This project was generated by EXE Forge. It contains everything needed to build a Windows NSIS installer.

## Option 1: Build Locally (Windows)

1. Run `circle-survivor-v120-ultimate-_build.bat`
2. It will:
   - Download your source file
   - Compile it to an .exe
   - Download NSIS if not installed
   - Build a professional installer: `circle-survivor-v120-ultimate--Setup.exe`
3. Run the installer to install your app

## Option 2: Build on GitHub (Cloud)

1. Create a new repository on GitHub
2. Copy all files from this folder to the repo
3. Push to GitHub
4. GitHub Actions automatically builds the installer
5. Download the installer from Actions → Artifacts or Releases

## Files

- `original.html` - Your source file
- `installer.nsi` - NSIS installer script
- `.github/workflows/build.yml` - GitHub Actions workflow
- `circle-survivor-v120-ultimate-_build.bat` - Local build script

## Requirements (Local Build)

- Node.js (for Electron)
- Internet connection (for downloading NSIS and dependencies)

## Requirements (GitHub Build)

- A GitHub account
- No local tools needed - GitHub Actions has everything pre-installed
